# Project Rules for AI Assistants

Animated diagram GIFs, generated as one SVG per frame → librsvg → ffmpeg. Plus
a browser editor for tuning geometry.

Full detail in `CLAUDE.md`, `docs/ARCHITECTURE.md`, `docs/DECISIONS.md`,
`docs/ASSETS.md`, and especially `docs/GOTCHAS.md`.

## Hard constraints

- **Python stdlib only.** No Pillow, numpy, or lxml. Shell out to
  ImageMagick/ffmpeg for image work; parse PNG/JPEG dimensions from headers.
  Requires `rsvg-convert` and `ffmpeg` on PATH.
- **`main` is protected.** Branch and open a PR. Push over SSH, not HTTPS.
- **No AI attribution** in commits, PRs, or any artifact.
- **Never commit `examples/disasters_ingest/assets/`** or its `editor.html` —
  third-party artwork.

## Rules that prevent known bugs

These all describe failures that already happened. Each produced a working-looking
wrong result with exit code 0.

- **Any SVG that references sprites must be written inside the project tree.**
  librsvg refuses resources outside the document's own directory and fails
  silently. Never render a scene from `tempfile.gettempdir()`.
- **Call `stage_assets()` from every entry point that renders artwork.** Only
  `main()` does it; `frame_svg()` alone yields a scene with no logos and no
  warning. The backdrop's byte size is the only tell.
- **Do not render frames into a subdirectory of `frames/`.** Sprite hrefs are
  absolute paths under `frames/assets/`; a frame one level deeper cannot reach
  it and loses every logo silently. Multi-target builds reuse `frames/` in turn.
- **Recovering a mark from the export: filter by its own palette, not just a
  coordinate window**, and keep the render window generous — ink touching the
  viewBox edge is clipped before `ink_bbox` measures it. Both failures yield a
  plausible-looking wrong icon. See `docs/ASSETS.md`.
- **Give an element with a background image its ground colour in CSS**, not just
  from the code that installs the image — that code may not run. And make the
  install path fail loudly on an unknown key instead of returning quietly.
- **Delete `frames/f*.svg` and `frames/f*.png`, never `frames/*`** — the latter
  takes the staged assets with it.
- **Compare assets by size/content, never mtime.** `cp -p`/`rsync -t` preserve
  timestamps and make an mtime check serve stale artwork forever.
- **Use `fill="none"` on containers**, plus a fat transparent stroke with
  `pointer-events:stroke` if it must be grabbable. `fill="transparent"` eats
  clicks aimed at children.
- **Never call a full re-render inside `pointerdown`** — it destroys the element
  being dragged and its `pointermove` listener. Update in place; re-render on
  release.
- **Look elements up by a `Map`, not `getElementById` + `CSS.escape`.** Ids match
  literally; escaping the dots guarantees no match.
- **Templates containing JS must be raw strings** (`r"""..."""`), and generated
  JS must pass `node --check` before you call it working.
- **Seed randomness with `zlib.crc32`, never `hash()`** — string hashing is
  salted per process.
- **Sketchy geometry: seed from shape identity, one PRNG per shape.** A shared
  stream re-jitters everything downstream whenever an element appears; the whole
  diagram boils.
- **Wrap `grep` in a build guard**: `{ grep ... || true; }`. It exits 1 on no
  matches, which `set -e` kills the build over — the success case.
- **Don't assume `log_message(fmt, *args)` args are strings** —
  `BaseHTTPRequestHandler` passes an `HTTPStatus` from `log_error`, and raising
  there aborts the response mid-flight.

## Sections (disasters example)

- **A section is NOT a crop.** Every section GIF shows the whole canvas; they
  differ by what MOVES (`SECTION_SCOPE`) and which frames they cover
  (`section_span`). Per-section viewports were built and deliberately removed.
- **Scope and span are both required.** Scope without span opens the GIF with
  40+ seconds of a frozen picture; span without scope shows another chapter's
  motion inside this one's frames.
- **Out-of-scope content is frozen, never deleted** — a hole in a connectivity
  diagram is worse than a still line.
- **Dim flows as well as blocks.** A frozen amber flow is the loudest thing on
  the canvas; `emphasis()` covers blocks (STAC always bright), `flow_emphasis()`
  covers flows (no STAC exemption).
- **Every chapter lives on the one timeline**, so adding one extends `TOTAL`
  for every section. That is deliberate — the combined journey is this timeline
  with scopes handing off.

## Patterns to follow

- Route every tunable coordinate through `overrides.*`; that registers a handle
  and the editor is generated from the registry.
- Labels use `overrides.offset`, anchored to what they name — absolute label
  positions detach the first time they are nudged.
- A stage declares its **subject**; caption placement is derived.
- Prefer asserting a cheap invariant (output size, frame count) over trusting an
  exit code, and point guards at an artefact that actually contains what they
  check.
